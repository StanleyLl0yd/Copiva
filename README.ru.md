# Copiva

**Быстрый нативный менеджер истории буфера обмена для macOS.**

[English](README.md) · [План разработки](docs/ROADMAP.md) · [Участие](CONTRIBUTING.md) · [Безопасность](SECURITY.md)

> **Статус: M0 / начало разработки.** Сейчас в репозитории минимальный собираемый каркас приложения в строке меню, а не готовый менеджер буфера. Текущая версия — 0.0.1.

## Запланированные возможности

- Вызов компактной панели одним настраиваемым сочетанием клавиш, рядом с местом ввода.
- Автоматическая история и мгновенный поиск с управлением с клавиатуры.
- Закрепление элементов с бессрочным хранением, включая перезагрузки и очистку обычной истории.
- Два режима вставки: с исходным форматированием и Plain Text, прямо из истории.
- Сохранение поддерживаемых исходных представлений текста и изображений.
- Настройки хранения обычной истории, независимые от закреплённых элементов.
- Локальная работа и защита конфиденциального содержимого.

Все перечисленное — **требования, а не уже реализованные функции**.

## 0.0.1

[Скачать 0.0.1](https://github.com/StanleyLl0yd/Copiva/releases/tag/v0.0.1): macOS 26+, Apple Silicon и Intel. Это текущий каркас для проверки запуска, меню и Quit; история буфера ещё не реализована. Подпись ad-hoc, без Apple Developer ID и нотарификации Apple. Установка и чек-лист проверки приведены в описании релиза и Issue #2.

## Разработка

macOS 26+, Xcode 26+, Swift 6.2+.

```sh
swift build
swift test
swift run Copiva
```

SwiftPM-приложение пока используется как каркас разработки. Подписанный `.app` и DMG появятся на следующих этапах.
