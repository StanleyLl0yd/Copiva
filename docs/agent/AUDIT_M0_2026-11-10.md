## Actual implementation and trust boundaries

SwiftPM defines a SwiftUI executable, a small domain target and one XCTest target. `CopivaApp` is the framework-driven `@main` entry point. Its menu-bar window shows development text and terminates through AppKit. App identity constants and the public Codable `PasteMode` enum are the only domain API.

There is no clipboard observer, global input hook, Accessibility request, paste engine, SQLite/FTS5 store, pinned retention, managed payload storage, image/file adapter, network client, migration, launch-at-login implementation, app bundle packaging or release pipeline. Those surfaces were checked for absence throughout the tree; they were not treated as implemented or runtime-tested. No persistence compatibility or user-data cleanup occurs. The provisional SF Symbol remains unchanged; no canonical icon exists.

The current executable has no clipboard data or network boundary. No confirmed exploitable production-code vulnerability or justified behavior-changing source fix was found in either static pass. Future M1–M4 privacy and data-loss risks remain acceptance requirements, not claims about current coverage.
