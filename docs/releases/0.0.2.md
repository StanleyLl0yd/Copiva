# 0.0.2

Сборка Copiva для проверки истории буфера обмена на Mac с Apple Silicon и macOS 26 или новее. Это описание подготовленного приложения; наличие файла в репозитории не означает публикацию релиза или приёмку M1.

## Что можно проверить

- Запись новых текстовых копирований после явного согласия, пауза и продолжение без захвата старого буфера.
- Локальная история SQLite, поиск по началу слов на русском и английском, сохранение между запусками.
- Окно по настраиваемому сочетанию клавиш; стрелки для выбора, Enter для вставки, Command-Enter для копирования и Escape для закрытия.
- Обычное копирование без дополнительных разрешений. Автоматическая вставка запрашивает Accessibility только по явному действию и требует проверки исходного приложения и поля.
- Настройки ограничения истории, исключения приложений и очистка с подтверждением.

Сейчас сохраняется простой текст. Закрепления, сохранение RTF/HTML, изображения и файлы, положение у текстового курсора и локализация интерфейса остаются в следующих этапах. Окно открывается у указателя мыши. Приложения без подходящего Accessibility-интерфейса используют копирование и ручной Command-V.

## Перед проверкой

Текст хранится на этом Mac без шифрования. Известные конфиденциальные метки пропускаются, но не каждый пароль можно распознать. Исключения определяются по приложению на переднем плане в момент наблюдения. macOS может отдельно запросить доступ к буферу; при постоянном запрете запись останавливается с пояснением. Для проверки используйте вымышленные примеры.

Подпись — ad-hoc, без Apple Developer ID и нотарификации Apple. Если macOS блокирует запуск, разрешите именно Copiva в «Системные настройки → Конфиденциальность и безопасность»; не отключайте Gatekeeper целиком.

Сценарии проверки и форма результатов — [MANUAL_TESTING.md](../MANUAL_TESTING.md), учёт приёмки — issue #6. Присутствие обычного числового номера не означает готовность стабильного выпуска.

## English

Apple Silicon-only build for macOS26+. Includes opt-in plain-text recording, local SQLite history/search, configurable global shortcut, keyboard picker, marked Copy, conservative explicit AX-verified Paste, retention/exclusions and confirmed clear. The picker uses the pointer fallback. No rich representations, images/files, pinning, caret positioning or interface localization yet.

History is local plaintext; recognized privacy markers and foreground-based exclusions cannot identify every secret. macOS may separately request clipboard-read access; permanent denial stops recording. Browsing/Copy need no Accessibility permission; explicit Paste may request it, with manual Command-V fallback for unsupported targets. Ad-hoc signing only, without Developer ID or Apple notarization. Use synthetic samples and the manual checklist; M1 acceptance and publication authorization remain separate from artifact construction.
