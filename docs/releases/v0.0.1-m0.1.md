# Copiva 0.0.1-m0.1 — проверка M0 на Mac

**Это предварительная тестовая сборка каркаса приложения. История буфера обмена, поиск, горячие клавиши и вставка ещё не реализованы.**

- macOS 26.0 и новее; универсальная `.app` для Apple Silicon и Intel.
- ZIP содержит `Copiva.app`; рядом опубликованы `SHA256SUMS` и `BUILD-INFO.json`.
- Ad-hoc-подпись проверена при упаковке. Подписи Apple Developer ID и Apple notarization нет.
- Каноническая иконка ещё не утверждена; новая иконка не создавалась.

## Установка и проверка

1. Скачайте `Copiva-v0.0.1-m0.1-macos-universal.zip`, распакуйте ZIP и перенесите `Copiva.app` в «Программы».
2. Откройте приложение. Если macOS блокирует непроверенного разработчика, используйте разрешение для этого приложения в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Не отключайте Gatekeeper целиком.
3. Проверьте появление значка буфера в строке меню и открытие окна по нажатию.
4. Проверьте кнопку **Quit Copiva**: приложение должно завершиться, значок — исчезнуть.
5. Сообщите модель/тип процессора Mac, версию macOS и результаты запуска, меню, Quit и наличия неожиданных запросов разрешений. Каркас не должен запрашивать Accessibility или Input Monitoring.

Эта публикация позволяет выполнить ручную приёмку M0. Она не закрывает M0 и не является стабильным подписанным/нотарифицированным релизом. Публикация разрешена владельцем в чате 2026-11-10; точный коммит и успешные проверки указаны ниже. Исполняемые файлы собираются только в GitHub Actions.

## English

Owner-requested M0 hardware-acceptance prerelease for macOS 26+, Apple Silicon and Intel. This is the existing menu-bar scaffold with launch, menu and Quit behavior only; clipboard history, search, shortcuts and insertion are not implemented. The app has a verified ad-hoc signature, without Developer ID signing or Apple notarization. Report hardware/OS and launch/menu/Quit/unexpected-permission results in issue #2. M0 acceptance and production release gates remain open.
