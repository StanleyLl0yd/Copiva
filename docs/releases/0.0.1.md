# 0.0.1

Первый каркас Copiva для macOS 26 и новее, Apple Silicon и Intel.

## В этой версии

- Приложение `Copiva.app` с окном из строки меню и кнопкой **Quit Copiva**.
- ZIP, SHA-256 и сведения о точном исходном коммите и сборке.
- История буфера обмена, поиск, горячие клавиши и вставка пока не реализованы.

Приложение имеет проверенную ad-hoc-подпись. Подписи Apple Developer ID и нотарификации Apple нет; это не подтверждённый производственный выпуск.

## Установка и проверка

1. Скачайте `Copiva-0.0.1-macos-universal.zip`, распакуйте и перенесите `Copiva.app` в «Программы».
2. Откройте приложение. Если macOS блокирует непроверенного разработчика, разрешите запуск именно Copiva через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Не отключайте Gatekeeper целиком.
3. Проверьте запуск, значок и окно в строке меню, кнопку **Quit Copiva** и отсутствие неожиданных запросов Accessibility/Input Monitoring.
4. Сообщите модель/тип процессора Mac, версию macOS и результаты проверки в Issue #2.

## English

Native menu-bar application scaffold for macOS 26+, arm64 and x86_64. Launch/menu/Quit only; clipboard history/search/shortcuts/insertion are not implemented. Ad-hoc signed, without Developer ID signing or Apple notarization. Download the ZIP, install the app and report hardware/OS and launch/menu/Quit/unexpected-permission results in issue #2. Version numbers and GitHub release titles use numeric X.Y.Z only; this is an ordinary GitHub Release, without a prerelease marker. Product readiness and signing limitations remain explicit.
