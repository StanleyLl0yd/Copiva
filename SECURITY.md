# Security policy

Copiva handles potentially sensitive clipboard content. Security and privacy reports are important even during early development.

**Please do not publish sensitive data or exploit details in public issues.**

Report a suspected vulnerability privately using GitHub's **Report a vulnerability** feature in the repository's Security tab, if available. If that is unavailable, contact the maintainer privately through their GitHub profile rather than opening a public issue with exploit details.

There is no stable release yet, and no security response SLA is promised.
