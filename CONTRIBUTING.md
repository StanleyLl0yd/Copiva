# Contributing

Thank you for your interest in Copiva. The project is in early development.

- Open an issue before proposing a large feature or architecture change.
- Use one focused branch and pull request per change.
- Add or update tests for behavior changes; run `swift build` and `swift test` on macOS 26+.
- Describe user-facing effects and any security/privacy implications.
- Do not include clipboard contents, credentials, signing keys or personal information in logs, screenshots or issues.
- Keep the default branch clean; no release artifacts or unreviewed binaries in source control.

Contributions are accepted under the repository's MIT license.
